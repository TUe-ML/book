# Regression

## Recommended Literature

If you want to read up further on this topic, the following material is recommended.

**Bishop. Pattern recognition and machine learning. 2006.**
- Section 3.1 _Linear Basis Function Models_, and
- Section 3.2. _Bias-Variance Decomposition_     

**Friedman, Hastie, and Tibshirani. The elements of statistical learning. 2001**
- Sections 2.6 on _Statistical Models, Supervised Learning and Function Approximations_
- Section 2.9 on _Model Selection and Bias-Variance Tradeoff_, and
- Chapter 3 on _Linear Methods for Regression_ (in particular sections 3.1 and 3.2).
